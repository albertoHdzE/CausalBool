# Cleaning Bitacora

## Purpose

This log records every cleanup action performed on the `clean` branch after the branch was rebuilt from `origin/main`.

The intent is:

- make every deletion or move auditable
- keep a rationale for each action
- preserve a rollback trail relative to the pre-rebuild backup branch
- separate low-risk document cleanup from higher-risk source-code cleanup
