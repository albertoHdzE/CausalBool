# Cleaning Bitacora

## Purpose

This log records every cleanup action performed on the `clean` branch after the branch was rebuilt from `origin/main`.

The intent is:

- make every deletion or move auditable
- keep a rationale for each action
- preserve a rollback trail relative to the pre-rebuild backup branch
- separate low-risk document cleanup from higher-risk source-code cleanup

## Baseline

- Working branch: `clean`
- Pre-rebuild safety branch: `backup/clean-pre-rebuild-20260621`
- Clean branch rebuild commit: `47aa0e5` (`Rebuild clean branch without local datasets or build artifacts`)

## Wave 1

### Scope

- Focus only on document/manuscript hygiene.
- Do not remove core scientific source code.
- Prefer archival moves over deletion for historically meaningful drafts.
- Delete only files that are clearly generated byproducts or placeholders.

### Planned actions

1. Clarify manuscript/document roles with README files.
2. Move obsolete AI-assisted draft variants out of the top level of `doc/finalpaper/` into an explicit archive subtree.
3. Delete pure build or placeholder artifacts that do not preserve source content.
4. Keep active manuscript sources and current paper-workspace files in place.

### File classification policy for Wave 1

- Keep in active root:
  - current manuscript sources
  - scripts that generate sections/manuscripts
  - figure sources and substantive figures
- Move to archive:
  - obsolete draft variants that still have historical value
  - AI-assisted exploratory drafts that document wording evolution but are not active build targets
- Delete:
  - placeholder files
  - generated LaTeX byproducts with no source value
