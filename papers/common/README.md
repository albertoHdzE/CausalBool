# Common Scientific Base

This directory defines the common source-of-sources for all paper tracks.

It is a navigation and governance layer, not a duplicate storage area.

## Canonical Starting Points

- Theory backbone: `doc/newIntPaper/docProcess.tex`
- Experimental and validation backbone: `doc/newIntPaper/expProcess.tex`
- Core deterministic code: `src/Packages/Integration/`
- Deterministic test layer: `tests/MUnit/`
- Shared experiment outputs: `results/`
- Shared repository-level figures: `figures/`
- Method derivations: `papers/method/derivations/`
- Nature execution provenance: `workspaces/claude-nature/paper/`

## Historical Material That Still Matters

- `doc/newIntPaper/` remains the main lineage and process-history tree.
- `doc/finalpaper/` remains the manuscript assembly and synthesis tree.
- `workspaces/claude-nature/` remains the active Level 8 reproducibility workspace.

## Interpretation Rule

Tickets, phased plans, and old protocol drafts are no longer the preferred first interface for new paper creation.

Use them only when you need to recover:

- why a decision was taken
- how an experiment was gated
- where a result first entered the project
- what provenance supports a locked artifact
