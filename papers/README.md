# Paper Programme

`papers/` is the canonical entrypoint for paper-oriented work in this repository.

Use this directory first when starting any AI-assisted writing, evidence review, or paper-planning task.

## Programme Structure

- `common/`: curated common scientific base shared across paper tracks.
- `method/`: first paper track focused on the formal method, gate formulae, validation, and manuscript preparation.
- `nature/`: active Nature-oriented paper track and its reproducibility anchors.

## Working Rule

1. Start from `papers/common/`.
2. Move into the relevant paper track only after the shared theory, results, and conventions are clear.
3. Use older plans, tickets, and protocol drafts only as archival provenance when a decision or result needs historical recovery.

## Why This Layer Exists

The repository evolved from one main Nature campaign into a three-paper programme. Historical execution artifacts still matter, but they should not be the first navigation surface for future AI work.

This directory provides that clean entry layer without destroying the underlying provenance.
