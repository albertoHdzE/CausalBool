# Complexity Analysis — 10-node mixed-gate network

Standalone Python experiment that computes the four complexity measures
reported in the "Mechanism Description Versus Dataset Complexity" subsection
of the method paper (Table 2).

## What is computed

| Measure | Symbol | Paper value | Formula |
|---------|--------|-------------|---------|
| Formula components | C_formula | 23 | structural pieces per gate (compressionWeight) |
| Programme length (primary) | D_schema | 232.72 bits | catalogue-free: the node's schemata written out |
| Programme length (catalogue) | D_formula | 135.66 bits | gate + in-degree + input-set + parameter coding |
| Shannon content | H_total | 10 229.61 bits | H_binary(p_overall) × 2^n × n |
| Compressed output | ZIP_bits | see note | zlib(CSV) × 8 |

## Running

```bash
python3 complexity_analysis.py
```

No third-party dependencies.  D_formula, C_formula, ZIP and H_total use only
the standard library; D_schema delegates to the repository's single
description-length owner, `src/description_lengths.py` (AUDIT03/R2b), which in
turn reuses `minimal_dnf` from `index-deconvolution/`.  That intra-repository
import is deliberate: a second copy of either routine is the defect the audit
removed.  Outputs `complexity_results.json` with all computed values.

## Formulas

**C_formula** (`compression_weight` in the script) counts the symbolic pieces
in the closed-form index-set formula for each gate:

| Gate | Weight |
|------|--------|
| AND / OR / NAND / NOR | 1 + d |
| XOR / XNOR / MAJORITY / KOFN | 2 |
| NOT | 1 |
| IMPLIES / NIMPLIES | 3 |

Source: `compressionWeight` in
`tests/MUnit/Mixed/TSK-MIXED-001-FormulaVsExhaustive.m`.

**D_formula** (`encode_node_cost`) encodes each node i as:

```
log2(K) + log2(C(n, d_i)) + gate_specific_bits
```

where K = 12 (full gate catalogue), n = 10, d_i = in-degree, and
gate_specific_bits encode the threshold (KOFN), pair (IMPLIES/NIMPLIES),
negation target (NOT), or a single polarity bit (all others).

Source: `encodeCostBits` in
`tests/MUnit/Mixed/TSK-MIXED-001-FormulaVsExhaustive.m`.

**H_total** is the binary entropy of the overall fraction of 1s in the
1024 × 10 output table, multiplied by the total number of output bits.

Source: `pOverall / shannonOverall` computation in the same test script.

## Superseded values (corrected 2026-08-14)

The value 1600 bits (200 bytes) reported in the manuscript came from an
archived Wolfram ZIP file (`OutputsBaseline.zip`) that was generated by the
original test run.  Inspection of that file reveals it contains a 64-byte
path-reference string rather than the compressed output table — a Wolfram
export artefact.

This companion script instead computes `zlib.compress` of the actual 20 480-byte
CSV, giving ~1252 bytes (~10 016 bits).  The scientific conclusion is unchanged:
D_formula (101 bits) is roughly two orders of magnitude smaller than the
losslessly compressed output representation, and both are far smaller than the
raw Shannon content (10 230 bits).

## Correction record (2026-08-14)

Two figures reported in earlier revisions of both manuscripts were invalid and have
been superseded.

**ZIP = 1600 bits** was a measurement artefact: the archived Wolfram ZIP file contained
a 64-byte path-reference string rather than the compressed output table. Correct value,
by zlib -9 over the actual CSV: **10016 bits**.

**D_formula = 101.07 bits** was not a valid description length. The encoding charged
log2(C(n,d)) for the input set without transmitting d, so a decoder could neither
determine the width of that field nor read it as an index into the d-subsets of [n];
the code was not uniquely decodable. A log2(n+1) in-degree field is now charged per
node, giving **135.66 bits**.

Neither correction alters any conclusion: the mechanism remains two orders of magnitude
below every description of its behaviour. Both are propagated to `comp_paper.tex`,
`manuscript_formal/method_paper.tex`, the notebooks, and `encodeCostBits` in
`tests/MUnit/Mixed/TSK-MIXED-001-FormulaVsExhaustive.m`.

Archived artefacts under `results/tests/mixed001FormulaVsExhaustive/` predate these
corrections and are retained for provenance; they are not authoritative. The
authoritative outputs are `complexity_results.json` and `bdm_results.json` in this
directory.
