**Purpose.** Coarse-grain the value axis (scale-free), treat the price-level
sequence as the repertoire of a Boolean/CA network, and ask whether it
deconvolves to a deterministic rule under the programme's control triad.

well-posedness obstruction — the real methodological gain; (1) the control triad
separates once persistence is removed; (2) the market has no deterministic rule,
even here.
