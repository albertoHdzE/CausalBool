# Protocol: Discovering Behaviour Tables in Uncontrolled Information

A knowledge-transfer document for an agent that will take this task from scratch.
The subject is purely informational. The source of the data is irrelevant; the
method must work for any binary sequence of any length. No assumption is made
about what generated the information.

---

## 1. Context

There are two regimes for finding order in an information stream.

The controlled regime. When the generating structure is known in advance, one can
build, for each observed unit, a behaviour table: a small array whose columns are
the elementary processes that place the ones of that unit across the index, and
whose rows are the numbers those processes emit. From the behaviour table one
reads a behaviour rule, a compressed expression of how the information is
distributed, and one can often name the rule as a specific canonical operation and
formalise it as a closed-form index-set formula. This has been achieved and
verified: for controlled generators of complex behaviour with known structure, the
behaviour tables, the behaviour rules, and their formal naming are recovered
exactly. The controlled regime is a solved problem and a proof of principle: order
can be recovered where it exists.

The uncontrolled regime. Here the generating structure is unknown. We are handed a
raw sequence and nothing else. We do not know the units, we do not know which
units participate, and we do not know the processes. The behaviour tables are no
longer given; they are the objective. This document defines the task of
discovering them.

The controlled methods and canonical rules are not to be imposed on the
uncontrolled data. They were the scaffolding that proved order is recoverable.
The task now is to generalise the discovery itself: to find, in an unknown
distribution of digits, the process columns that a behaviour table would contain,
and to express them as behaviour rules, tolerant of noise.

This is an extension of algorithmic information theory into the long-term regime.
The established algorithmic-information practice summarises a short string by a
single complexity value. That view is blind to how order is distributed along a
long sequence. The objective here is the whole picture: not one program that
reproduces the sequence, but the set of local processes whose composition
reproduces it, and the law by which those local processes are distributed along
the index.

---

## 2. The object

Let the raw input be a sequence of values. Binarise it. The most neutral
binarisation writes each value in a fixed number of bits, so the input becomes a
two-dimensional binary array: one axis is the index (position along the sequence),
the other axis is the bit position within a value. Each bit position is a
candidate unit, the analogue of a node; there is one unit per digit of the
binarisation. Other binarisations are admissible and should be tried; the method
must not depend on a particular one.

The atomic observable is the set of index positions at which a chosen feature
occurs: the positions of the ones in a given bit column, or the positions at which
a short local pattern recurs. Call this set the occurrence set. The behaviour
table is, ultimately, a description of the arithmetic structure of the occurrence
set.

---

## 3. What a behaviour table is, precisely

A behaviour table is a small array of process columns. Each column is a
deterministic transform applied down the rows; each number in a row is that
transform's output and contributes to the behaviour rule. In the controlled
regime the columns observed were, in order:

1. the ordinals of the participating units (which units place ones in this
   occurrence set);
2. a shift of those ordinals (for instance the ordinal minus one), which acts as
   an exponent;
3. a place-value, the base raised to that exponent, so that the participating
   units are mapped to a positional weight;
4. the ratio between consecutive place-values, an index n mapped to element n+1
   divided by element n, which exposes the self-similar spacing (a constant ratio
   is a geometric, self-similar law).

The behaviour rule then reads the occurrence set as a nested run-length
expression: so many positions of one symbol, then a repeated sub-block, then a
repeat of the repeat, and so on. The nesting is the soft-fractal signature: a
pattern that reappears at several scales, generated by the ratio column.

The essential point for the uncontrolled regime: the process columns are not to be
assumed. They are unknowns. In the controlled case they turned out to be ordinals,
exponents, place-values and ratios. In unknown data the agent must discover which
transforms actually describe the observed occurrence set. Finding the columns is
finding the rule.

---

## 4. Goal

Given an uncontrolled binary sequence, and nothing about its origin, produce:

1. behaviour tables for the discovered units: for each unit, the process columns
   (the transforms) that reproduce its occurrence set;
2. behaviour rules: the compressed, nested run-length expressions read from the
   tables;
3. where possible, a name and a closed-form expression for each process column,
   so that a rule can be stated formally rather than only tabulated;
4. an explicit account of the residual: the part of the sequence not captured by
   any discovered process, treated as noise;
5. a forecast: a use of the discovered structure to project the sequence forward,
   validated out of sample.

If the agent produces behaviour tables whose header processes are identified and
whose behaviour rules compress the occurrence sets of an uncontrolled sequence,
and if those rules recover a predictable trend beyond a shuffle control, the
objective is met.

---

## 5. Method to generalise

The discovery proceeds from the occurrence set outward. The following are
directions, not a fixed recipe; the agent is expected to invent.

Discover the units. Do not assume how many units there are or which participate.
Probe each candidate bit position and each candidate local pattern for whether it
carries any regularity at all; discard the inert ones. A unit that never departs
from randomness contributes no rule.

Discover the arithmetic of the occurrence set. For a surviving unit, examine the
positions of its feature. Look for: repetitions, and repetitions of repetitions
(nested run-lengths); constant or slowly varying ratios between successive gaps (a
geometric, self-similar spacing, the analogue of the ratio column); expressibility
of the positions as sums of a few base weights plus a free offset family (a pivot
part that is fixed and an offset part that tiles). The behaviour table is the
tabulation of whichever of these transforms is present.

Discover the processes as columns. Each regularity that survives becomes a process
column: the transform that emits the numbers, and the numbers themselves. Compose
the columns into a candidate behaviour rule and test whether it regenerates the
occurrence set. Retain only columns that genuinely compress: a process that needs
as many parameters as it explains is not order, it is transcription.

Separate pivots from noise. In uncontrolled data a perfect global fit is not
expected. The positions that a discovered process reproduces exactly are the
pivots; they are the high-information anchors. The positions that no process
reaches are the residual. Report both. Study how the pivots are distributed along
the index: uniform, clustered, or self-similarly spaced. That distribution is
itself a behaviour rule at a higher level, and it is often the most informative
object when the direct sequence is noisy.

Recover the trend. Use the pivots and their distribution to forecast. The claim to
be tested is not that the whole sequence is deterministic, but that its structured
part supports a projection that beats a random baseline out of sample.

## 6. Evidence in hand

The controlled regime is verified: for synthetic generators of complex behaviour
with known structure, the behaviour tables, behaviour rules and their formal names
are recovered exactly, and an independent re-computation reproduces the results to
the last digit. This establishes that the discovery target is real and that the
instruments recognise order when it is present.

For an uncontrolled sequence at its finest sampling, four independent analyses
agree that there is no single global rule: the direct one-step relation is
self-contradictory on the recurring patterns; the whole-sequence map does not
generalise because configurations essentially never recur; a search for a
deterministic backbone finds nothing beyond a multiple-testing artefact; and the
information-distribution decomposition compresses a structured control perfectly
while leaving the raw sequence at its shuffle baseline.

The same analyses also produced the first positive signal in the direction of this
protocol: the local structure is not distributed uniformly along the index. Cut
into non-overlapping windows and scored by a Lempel-Ziv complexity, the dispersion
of the local-complexity profile exceeds that of a time-shuffle. The islands of
order cluster along the index. This is exactly what the protocol tells us to
pursue: the order is in where the pivots fall, not in a global rule.

---

## 7. Guardrails

Agnosticism. Assume nothing about the origin of the data. Use no domain knowledge.
The method is judged only as informational structure discovery and must run
unchanged on any binary sequence.

No transcription disguised as order. A behaviour rule counts as a discovery only
if it is strictly shorter than the occurrence set it explains. A process column
with as many free numbers as it reproduces is not a column.

Out-of-sample and against a null. Any predictive claim is committed on an earlier
part of the sequence and evaluated on a held-out later part. Every discovered
regularity is compared against a time-shuffle of the same sequence, which destroys
the temporal order while preserving the marginals; a regularity that is no stronger
on the real sequence than on its shuffle is an artefact of multiple testing, not
order.

Honesty about noise. The residual is reported, not hidden. The success criterion
is a structured part that carries information and a forecast that beats the null,
not a perfect fit.

---

## 8. Success criterion

The battle is won if, for an uncontrolled binary sequence of any length and
unknown origin, the agent:

1. discovers behaviour tables whose process columns are identified transforms;
2. states behaviour rules that compress the occurrence sets;
3. formalises at least some process columns as named, closed-form expressions;
4. characterises the distribution of the pivots along the index; and
5. turns that structure into an out-of-sample forecast that beats a shuffle
   control.

The controlled regime already yields 1 to 3 when structure is known. The open
frontier is to yield them when it is not, and to add 4 and 5.

---

## 9. Starting materials

A foundational codebase exists and may be used as a toolbox, but its assumptions
must not be imposed. It provides: exact detection of which units a pattern depends
on, by single-position perturbation; a minimal schema (disjunctive) cover of an
occurrence set, the pivot-and-offset decomposition; a Lempel-Ziv complexity and a
run-length signature for one-dimensional patterns; and a windowed local-complexity
profile with a shuffle control. These are means, not the method. The method is the
discovery of the process columns of the behaviour tables in unknown data, and the
expression of them as behaviour rules that survive a null and forecast a trend.
