# Level 12 — Symbolic action dynamics

**Purpose.** Test whether the secret of the market clock is not the direction of
prices but a timing pattern carried by the *actions* (buy/sell symbols), each
part scored against the return-shuffle null.

**Key result (qualitative).** The action-type order alone is forced alternation
(conditional entropy ≈ 0 bits): the "what" is not the secret; see the bitácora
for where the information actually lives.
