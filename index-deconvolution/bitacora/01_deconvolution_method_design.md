# Bitacora 01 — The Index-Set Deconvolution Method

Date: 2026-07-09
Status: complete and verified

## Problem statement

Given only the output repertoire of a synchronous Boolean network (a `2^n x n`
binary matrix), with the generating definition `(C, D)` hidden, recover a
network definition that reproduces the repertoire exactly. The recovered
definition is judged correct if and only if replaying it through the forward
method yields the identical repertoire. Success is exact, not statistical.

This is the index-set analogue of the algorithmic-information deconvolution of
Zenil and colleagues, who recover a generating cellular-automaton rule from a
scrambled space-time diagram by perturbation against an approximate complexity.
Here the forward method is an exact index-set formula, so the inverse is exact.

## Core idea

The forward transform factorises over nodes (Bitacora 00): column `k` of the
repertoire is a Boolean function of the connected inputs of node `k` alone.
Therefore the deconvolution factorises into `n` independent single-column
problems. Each is solved in two exact steps.

### Step 1 — essential-variable detection (pivots versus sumandos)

For output column `O_k` and each bit `i`, bit `i` is **essential** if there
exists an input `x` with `O_k[x] != O_k[x XOR 2^i]`. By the pivots/sumandos
structure, the essential bits are exactly the connected inputs (the pivots),
and the non-essential bits are the disconnected offset dimension (the
sumandos). This is a single-bit perturbation performed against the exact
column, costing `O(n · 2^n)` per node.

The recovered essential set is the **functional connectivity** of the node. For
every non-degenerate gate this equals the structural connectivity declared in
`C`. When a gate is functionally independent of a declared input — which occurs
for certain CANALISING parameterisations — the functional connectivity is a
strict subset of the structural connectivity. This is not an error: the
repertoire genuinely does not depend on that input, so the structural edge is
non-functional. The deconvolution reports what the data determine.

### Step 2 — gate identification

Restrict the column to its essential variables to obtain a reduced truth table
of `m = |I_c|` variables (enumerated LSB-first over the essential variables in
ascending order). This reduction is well defined precisely because the
non-essential variables do not affect the output; the implementation asserts
this invariant as a correctness guard.

Identify the gate by matching the reduced truth table against the truth table
of every canonical candidate:

- AND, OR, XOR, NAND, NOR, XNOR, MAJORITY for any arity;
- NOT for arity 1; IMPLIES, NIMPLIES for arity 2;
- KOFN with a search over `k in 1..m`;
- CANALISING with a search over canalising index, canalising value, and
  canalised output.

The set of all matching candidates is the **equivalence class** of the recovered
function within the canonical family; it is reported in full. The
highest-priority member is chosen as the canonical representative. When no
canonical gate reproduces the function (which does not occur for repertoires
generated by the family, but is handled for robustness), the function is
recorded as an explicit look-up table so that reconstruction remains exact.

### Reconstruction and verification

The recovered network sets row `k` of `C` to the indicator of the essential
set and node `k` of `D` to the canonical gate, with the gate applied to the
connected inputs in ascending order — matching the forward method exactly.
Verification replays each recovered column (from the per-node report, including
any look-up-table fall-back, so it is independent of gate naming) and checks it
against the original column. Exact equality on every column is the success
criterion.

## Why the inversion is exact

1. The essential set of a Boolean function is uniquely determined by the
   function; single-bit perturbation recovers it exactly and completely.
2. The reduced truth table is uniquely determined by the essential set and the
   column.
3. Some canonical candidate (or, failing that, the explicit look-up table)
   reproduces the reduced truth table by construction.
4. The non-essential variables do not affect the column, so replacing the
   structural connectivity by the functional connectivity leaves the column
   unchanged.

Hence the reconstructed network reproduces the repertoire column by column,
and therefore in full. The only non-uniqueness is the **naming** of the
recovered function when several canonical gates realise the same Boolean
function (for example, every gate reduces to the identity on a single essential
variable, so AND, OR, KOFN(1) and MAJORITY all match there). This non-uniqueness
is a property of the canonical family, not a deficiency of the method, and it
is reported explicitly as the equivalence class.

## Relationship to basins of attraction

The index-set method also enumerates the image of the repertoire (the set of
reachable output states) and thus the basins of attraction. The deconvolution
does not require basins for the per-node inversion, but the image provides an
independent global cross-check: the reconstructed network must have the identical
image and attractor structure, which follows automatically from exact
repertoire reproduction. This is noted as a validation invariant for the
forthcoming formal treatment.

## Implementation

- `src/causalbool.py` — forward model and gate semantics.
- `src/deconvolution.py` — `essential_variables`, `reduce_column`,
  `identify_gate`, `deconvolve`, `verify`.
- `src/network_generator.py` — seeded generator of consistent test networks.

of test cases.
