# Analysis Drafts Archive

This directory stores analysis scripts that were removed from active code locations because they are incomplete or clearly superseded by working implementations.

The files are preserved here for historical inspection and rollback safety.

Archive policy for this directory:

- keep draft files unchanged unless a later review extracts unique content
- do not import archived drafts from active workflows
- prefer the active implementation under `src/` when both draft and mature versions exist

See `mapping/move_delete_candidates.md` and `mapping/cleaning_bitacora.md` for the supporting rationale.
