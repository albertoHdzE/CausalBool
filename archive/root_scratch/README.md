# Root Scratch Archive

This directory stores former top-level scratch, debug, exploratory, and local test scripts that were moved out of the repository root during surgical cleanup on the `clean` branch.

These files were not deleted because they may still preserve useful troubleshooting context or historical workflow knowledge.

Archive policy for this directory:

- keep files unchanged unless a later cleanup pass has stronger evidence
- preserve original basenames for easy lookup against old notes or commits
- avoid treating archived scripts as active project entrypoints

See `mapping/cleaning_bitacora.md` and `mapping/move_delete_candidates.md` for rationale.
