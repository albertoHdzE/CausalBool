## Root Build Artifacts Archive

This directory contains generated byproducts that were created in the repository root (typically by compiling LaTeX documents or exporting ad hoc PDFs) and should not occupy the active top-level namespace.

Policy:

- move, do not delete, when the artifact could plausibly be useful for local review
- treat these files as regenerateable build outputs rather than canonical sources
- keep the repository root focused on active entrypoints and top-level documentation

Examples archived here include `.aux`, `.log`, `.out`, `.toc` files and accidental root-level PDFs or Office temporary files.
