# Finalpaper Workspace

`doc/finalpaper/` is a manuscript assembly area, not a single clean paper target.

## What stays at the top level

- active manuscript sources such as `final.tex`, `nature_draft.tex`, `nature_final.tex`, `together.tex`, and `together_full.tex`
- assembly and transformation scripts
- bibliographies
- figures and section files used by current manuscript builds

## What belongs in `archive/`

- obsolete draft variants
- AI-assisted exploratory drafts
- prompt/review conversations tied to discarded manuscript directions

## Cleaning note

Wave 1 of repository cleanup moves the clearly obsolete Gemini-era variants out of the top level so the active manuscript files are easier to identify.
