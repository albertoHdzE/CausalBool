# Finalpaper Archive

This archive holds manuscript variants that are historically useful but should not crowd the active `doc/finalpaper/` workspace.

## Current contents

- `ai_drafts/`: obsolete AI-assisted draft variants and review conversation material that informed wording experiments but are not active build targets.

## Policy

- Archive rather than delete when a file documents the evolution of the manuscript.
- Keep the active `doc/finalpaper/` root focused on current sources, scripts, and figures.
