# Historical Manuscripts

This directory stores historically meaningful manuscript branches that are no longer treated as active top-level writing sources in `doc/finalpaper/`.

Contents currently archived here:

- `final-draft.tex`: earlier manuscript branch explicitly referenced in later review and provenance material as the predecessor to the stronger `nature_draft` branch
- `final-draft.pdf`: compiled companion kept with the branch for review provenance
- `supInfo.tex`: supplementary LaTeX companion originally stored at the top level as `supInfo.txt`

Policy:

- archive rather than delete when a manuscript branch remains useful for comparison, provenance, or narrative lineage
- keep active manuscript roots focused on current sources such as `final.tex`, `nature_draft.tex`, `nature_final.tex`, `together.tex`, and `together_full.tex`
- preserve compiled companions when they are explicitly mentioned in historical review loops
