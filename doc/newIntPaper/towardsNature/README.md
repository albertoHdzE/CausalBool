# TowardsNature Workspace

This directory preserves exploratory material from the transition between the integration-era paper program and later Nature-facing manuscript work.

## Subdirectories

- `protocols/`: protocol drafts and escalation plans.
- `planning/`: planning notes and execution roadmaps.
- `reviews/`: external-style evaluations, critique notes, and conversation-derived review artifacts.
- `historical_code/`: historical code artifacts generated during the transition period; these are not the current source-of-truth implementation.

## Cleaning policy

- Preserve these files as historical context.
- Prefer reorganization over deletion.
- Treat code in `historical_code/` as archival unless a live workflow explicitly depends on it.
